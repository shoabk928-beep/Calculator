An industry-standard, high-performance command-line calculator written in modern C++. Designed with clean code architecture, robust input validation, and zero external dependencies.

---

## 📌 Executive Summary

This repository provides a lightweight, deterministic CLI application for core mathematical operations. Built to demonstrate software engineering best practices, memory efficiency, and defensive programming in C++.

---

## ✨ Core Features

* **Mathematical Operations:** Addition, Subtraction, Multiplication, Division.
* **Defensive Input Handling:** Built-in validation against invalid character inputs and runtime edge cases (e.g., division by zero).
* **Cross-Platform Support:** Fully compatible with Linux, macOS, and Windows environments.
* **Minimal Overhead:** Compiled directly to native binary code with no third-party library bloat.

---

## 🏗️ Architecture & Tech Stack

* **Language:** C++17 / C++20
* **Build System:** CMake / GCC / Clang / MSVC
* **Paradigms:** Object-Oriented Programming (OOP), Modular Design
